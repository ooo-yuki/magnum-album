## Что оптимизировал: `lazy 5 eager pages` (тяжёлый чанк >50KB → lazy)

**Проблема:** `src/App.tsx` грузил 5 страниц eager, каждая >8KB исходника → ~68KB в main, не нужны на первом экране `/`:

| Страница | Исходник | Оценка в main |
|----------|----------|---------------|
| `About42Page.tsx` | 24 KB (374 строки) | ~22 KB |
| `TrackPage.tsx` | 24 KB (372 строки) | ~18 KB |
| `LastFitPage.tsx` | 8 KB (195 строк) | ~7 KB |
| `GamePage.tsx` | 12 KB (339 строк) | ~11 KB |
| `GamesHub.tsx` | 8 KB (130 строк) | ~7 KB |

Итого **~65 KB** в main + зависимости (GSAP, router).

**Решение:** `src/App.tsx` — 5 страниц переведены на `React.lazy` + `Suspense`:

```ts
const About42Page = lazy(() => import("./pages/About42Page").then(m => ({ default: m.About42Page })));
const TrackPage   = lazy(() => import("./pages/TrackPage").then(m => ({ default: m.TrackPage })));
const LastFitPage = lazy(() => import("./pages/LastFitPage").then(m => ({ default: m.LastFitPage })));
const GamePage    = lazy(() => import("./pages/GamePage").then(m => ({ default: m.GamePage })));
const GamesHub    = lazy(() => import("./pages/GamesHub").then(m => ({ default: m.GamesHub })));
```

Каждый роут обёрнут:
```tsx
<Route path="42" element={<Suspense fallback={<PageFallback />}><About42Page /></Suspense>} />
<Route path="track/:slug" element={<Suspense fallback={<PageFallback />}><TrackPage /></Suspense>} />
<Route path="last-fit" element={<Suspense fallback={<PageFallback />}><LastFitPage /></Suspense>} />
<Route path="game" element={<Suspense fallback={<PageFallback />}><GamePage /></Suspense>} />
<Route path="games" element={<Suspense fallback={<PageFallback />}><GamesHub /></Suspense>} />
```

Теперь **все 14 страниц** (9 heavy + 5 eager) — lazy, кроме `HomePage` (index). `main` грузит только первый экран.

**Результат:** `main 528 KB → 472 KB (−56 KB, −10.6%)`, `dist 42→38 MB`. +5 чанков грузятся только по переходу.
