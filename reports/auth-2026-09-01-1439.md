function extractToken(req: Request): string | null {
  const auth = req.headers.get("authorization");
  if (auth && auth.startsWith("Bearer ")) return auth.slice(7).trim();
  const url = new URL(req.url);
  const qp = url.searchParams.get("token");

  return getCookie(req, "magnum_token");
}

## 🔍 Найденный баг #1 (единственный, критичный)

**Файл:** `server.ts:1462-1473`
**Строка:** `1462` (`if (url.pathname === "/magnum/api/ws"`)
**Симптом:** любой клиент с валидным WS handshake без `magnum_token`/`Authorization` получает `101` и попадает в дуэль как `Братуха_XXX`. Ретест 14:39 — `Братуха_324`, `room-mtirwlol-96ul`. Это обход кастом-авторизации (требование: вся экономика — только для залогиненных, без `localStorage`).

**Почему критично:** анонимы накручивают `magnum_leaderboard`/`duel` без аккаунта, ломают рейтинг/пресейв/экономику; после фикса 12/11 это должен быть 401.

**Доказательство:**

```
$ python3 raw-socket WS no-token
→ HTTP/1.1 101 Switching Protocols
→ {"type":"room","room":{"id":"room-mtirwlol-96ul","state":"waiting","players":[{"name":"Братуха_324","score":0}]},"you":"Братуха_324"}
```

Лог прогона: `/tmp/auth.log`

## План фикса (не применять в этом прогоне — только план)

1. **Строго требовать токен до upgrade** — `server.ts:1465-1471` заменить на:
   ```ts
   const token = extractToken(req);
   if (!token) return Response.json({ error: "unauthorized" }, { status: 401 });
   const u = await getUserByToken(token);
   if (!u) return Response.json({ error: "unauthorized" }, { status: 401 });
   const ok = server.upgrade(req, { data: { id: crypto.randomUUID(), username: u.username, roomId: null } });
   ```
   Убрать `?username=` fallback полностью (или оставить только как `displayName` внутри уже-авторизованной сессии, но не как вход).

2. **Фронт `src/components/Duel*.tsx` / `src/hooks/useDuel.ts`** — при `401` на WS показывать модалку `AuthStatus` («войди, братуха») и не пытаться `new WebSocket` без токена. Сейчас фронт шлёт `?username=...` без токена — после фикса будет получать 401, нужно обработать.

3. **Тест регрессии:** `python3` raw-socket без токена → ожидать `401` (не `101`); с валидным `Cookie: magnum_token=...` → `101` + `you === username из БД`.

4. **Опционально:** rate-limit на WS upgrade по IP (`checkRateLimit(`ws:upgrade:${ip}`, 10, 60_000)`) — антиспам.
