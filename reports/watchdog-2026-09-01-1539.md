## Баги (2 найденных, файл:строка)

### BUG-1 — `src/components/AiBot.tsx:77,319,340` — localStorage-утечка против спеки Neon-only

```ts
// AiBot.tsx:77
if(!balance){ try{ const v = localStorage.getItem("magnum_coins"); if(v) balance = Number(v)||0; }catch{} }
// AiBot.tsx:319,340
try { localStorage.setItem("magnum-frame-verified", "1"); } catch {}
```

Спека: *«all state in Neon Lakebase Postgres, custom auth without managed Neon Auth, multiplayer via WebSocket on Bun.serve, no localStorage»* (memory). `coins.ts:4` прямо пишет `localStorage полностью удалён, токен в cookie`. Но `AiBot` читает `magnum_coins` из localStorage как fallback баланса и пишет `magnum-frame-verified` в localStorage при верификации рамки. Результат: рассинхрон — после `/magnum/api/coins/add` Neon баланс 142, а в другом браузере/инкогнито AiBot берёт stale 0–X из localStorage и рекомендует неверные товары (`SHOP_SKINS_FOR_BOT` фильтр `price <= balance`). Также `frame/verify` → localStorage флаг переживает логаут и даёт ложный «verified» без `GET /magnum/api/frame/status`. Нарушает «каждая фича без спеки — баг» и `reviewer 404/health/tsc/tests`.

### BUG-2 — `src/components/ErrorBoundary.tsx:19` — `/magnum/api/log` 404, логи крашей теряются

```ts
// ErrorBoundary.tsx:19
const LOG_ENDPOINT = "/magnum/api/log";
// server.ts grep: 0 совпадений "/magnum/api/log", есть только "/magnum/api/reports"
```

`ErrorBoundary.componentDidCatch` шлёт `fetch(LOG_ENDPOINT)` при каждом краше страницы, но в `server.ts` (`Bun.serve` 2119–2242) ветки `if (url.pathname === "/magnum/api/log")` нет. Запрос попадает в SPA fallback (`try_files → /index.html`) и возвращает 200 HTML, а не 201 JSON. Ошибки не попадают в Neon `magnum_reports` / `magnum_moderation_log`, `handleReportCreate` не вызывается. В проде краши невидимы для мониторинга, watchdog не ловит 5xx по логам. Подтверждено `grep -rn` — 0 хендлеров, `curl /magnum/api/log → 200 html` (ожидалось 200 JSON или 404 явный).
