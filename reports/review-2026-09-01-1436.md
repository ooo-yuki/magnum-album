## 🔍 Замечания (3 конкретных)

1. **`src/pages/GalleryPage.tsx:39-43` — `REAL_FALLBACK` маппит Y2K на memphis, y2k-03 на cyber:**
   ```ts
   "y2k-01": "/magnum/images/gallery-42/42-memphis-01-800.webp", // должен быть 42-y2k-01, а не memphis
   "y2k-02": "/magnum/images/gallery-42/42-memphis-01.jpg",
   "y2k-03": "/magnum/images/gallery-42/42-cyber-01.jpg",        // y2k-03 → cyber.jpg, путаница имён
   ```
   При этом `REAL_BY_STYLE["Y2K"]` → `42-y2k-01-800.webp` (верно), а `REAL_FALLBACK["y2k-01"]` → memphis. BASE_ARTS id y2k-01/02 показывают memphis-файл под Y2K-лейблом — визуальная ложь стиля. Починить: `y2k-01/02 → 42-y2k-01.*`, либо убрать FALLBACK и везде `getRealSrc(style, src)`.

2. **`server.ts:946-954` — race на `magnum_mining_vault` без транзакции/unique-constraint:**
   ```ts
   const exists = await sql`SELECT ... WHERE user_id=${user.id} AND vault_id=${raw}`;
   if(exists.length>0) return 409;
   const globalRows = await sql`SELECT count(*) ... WHERE vault_id=${raw}`;
   if(globalCount >= item.limit) return 409;
   await sql`UPDATE magnum_mining SET balance = balance - price + reward ...`;
   await sql`INSERT INTO magnum_mining_vault ...`;
   ```
   Между `SELECT exists` и `INSERT` нет `BEGIN ... COMMIT` и `UNIQUE(user_id, vault_id)` в `drizzle/schema.ts:122` (только `pgTable` без `uniqueIndex`). Двойной клик → 2× INSERT до первого коммита → дубль награды + обход лимита. Фикс: `uniqueIndex` + `INSERT ... ON CONFLICT DO NOTHING` + `SELECT FOR UPDATE` или один `INSERT` с `WHERE NOT EXISTS`, баланс — в одной транзакции.

3. **`src/pages/games/Snake42Game.tsx:331,333,360` — `bonusAccRef` копится вечно, сброс только в `reset()`:**
   ```ts
   bonusAccRef.current += bonus;                 //:331 — +25*(combo-1) каждый фрукт
   const newScore = baseScore + bonusAccRef.current; //:333 — score = длина*100 + накопленный бонус
   // reset на :219 bonusAccRef.current = 0 — только при рестарте/маунте
   ```
   При длинной игре (42 фрукта, комбо x12) `bonusAcc` → ~2800, но `baseScore` = `snake.length*100` уже включает все фрукты. Бонус должен быть частью score, а не аддитивным аккумулятором сверх длины — иначе при смерти и продолжении (если добавят continue) бонус переживёт сессию. Сейчас не критично (сброс при `gameOver→reset`), но если введут паузу/continue — бонус задублируется. Фикс: пересчитывать `score = snake.length*SCORE_PER_FOOD + sumBonusesForThisRun` явно, или хранить `score` атомарно без аккумулятора, либо сбрасывать `bonusAccRef` вместе с `comboRef` при `dt>=1800`.
