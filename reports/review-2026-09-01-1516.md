## Замечания (3 конкретных)

### 1) `src/lib/galleryTokens.ts:41` — Y2K маппит не тот файл (P0)
```ts
"Y2K": "/magnum/images/gallery-42/42-memphis-01-800.webp", // сейчас memphis
```
В `src/pages/GalleryPage.tsx:32` правильно: `"Y2K": "/magnum/images/gallery-42/42-y2k-01-800.webp"` — рассинхрон. `REAL_BY_STYLE_FALLBACK` должен повторять `REAL_BY_STYLE`. Из-за дублирования Y2K и мемфис показывают один арт. Фикс: `Y2K -> 42-y2k-01-800.webp`. Заодно проверить `REAL_FALLBACK` в GalleryPage: `y2k-01` -> `42-memphis`, `y2k-03` -> `42-cyber.jpg` — перепутаны имена.

### 2) `src/pages/GalleryPage.tsx:39-43` — `REAL_FALLBACK` нейминг вводит в заблуждение
```ts
"y2k-01": "/magnum/images/gallery-42/42-memphis-01-800.webp",
"y2k-02": "/magnum/images/gallery-42/42-memphis-01.jpg",
"y2k-03": "/magnum/images/gallery-42/42-cyber-01.jpg",
```
3 из 7 маппингов указывают не на свой стиль (y2k -> memphis/cyber). Если это fallback для архива — ок, но имя ключа врет и тест `gallery-api-games.test.ts` (threshold 400B) не ловит логику. Предложение: переименовать ключи в `memphis-01`/`cyber-02` или поправить пути на `42-y2k-01.*`.

### 3) `server.ts` + `build.ts:1578` — двойной public sync без редиректа
`build.ts:1578` делает `cp -r public/images -> dist/images` и `measureDist` логирует 8 файлов — но `server.ts` отдает статику только под `/magnum/` (проверено: `/images/gallery-42/...` 404, `/magnum/images/gallery-42/...` 200). Любой внешний линк без префикса сломается. Не критично для SPA, но добавить редирект `/images/* -> /magnum/images/*` или 404-страницу с подсказкой. Также в `dist/` дублируются jpg (2.4M каждый) + webp — 12M на галерею; рассмотреть sharp ресайз jpg до 1600px.
