## 4) Баг #1 (minor, не критично) — порядок проверок в `handleEcoSubmit`

**Файл: `server.ts:918` `async function handleEcoSubmit(req)`**

Без токена и с невалидным телом `POST /magnum/api/eco/submit {}` отвечает `400 {"error":"score required"}` вместо `401`. Причина — валидация `score` идёт до `if (!authedUser) return 401`, поэтому аноним может прощупать валидацию (info leak, не bypass).

```ts

  let body = await req.json() ...
  const score = Number(body.score);
  if (!Number.isFinite(score)) return Response.json({ error: "score required" }, { status: 400 }); // ← до проверки auth
  if (authedUser) { ... insert ... }
  return Response.json({ error: "unauthorized — войди, братуха" }, { status: 401 });
}
```
