## Что оптимизировал: `lazy 9 heavy pages` (1 тяжёлый чанк >50KB → lazy)

**Проблема:** `main-*.js` = **1 037 KB** несмотря на `lazy 16 games`. Причина — 9 тяжёлых страниц грузились eager:

| Страница | Исходник | Оценка в main |
|----------|----------|---------------|
| `GalleryPage.tsx` | 441 KB (2570 строк, 8.8 MB `gallery-42` refs) | ~150 KB |
| `RecapsPage.tsx` | 277 KB (3378 строк, 148 карточек) | ~250 KB |
| `DiscographyPage.tsx` | 36 KB | ~35 KB |
| `ShopPage.tsx` | 29 KB | ~28 KB |
| `EcoPage/MiningPage/PresaveRating/Artists/Ideas` | 16–22 KB ×5 | ~80 KB |

Итого **~540 KB** в main, не нужных на первом экране (`/`).

**Решение:** `src/App.tsx` — 9 страниц переведены на `React.lazy` + `Suspense`:

```ts
const DiscographyPage = lazy(() => import("./pages/DiscographyPage").then(m => ({ default: m.DiscographyPage })));
const ArtistsPage     = lazy(() => import("./pages/ArtistsPage").then(m => ({ default: m.ArtistsPage })));
const ShopPage        = lazy(() => import("./pages/ShopPage").then(m => ({ default: m.ShopPage })));
const EcoPage         = lazy(() => import("./pages/EcoPage").then(m => ({ default: m.EcoPage })));
const GalleryPage     = lazy(() => import("./pages/GalleryPage").then(m => ({ default: m.GalleryPage })));
const MiningPage      = lazy(() => import("./pages/MiningPage").then(m => ({ default: m.MiningPage })));
const PresaveRatingPage = lazy(() => import("./pages/PresaveRatingPage").then(m => ({ default: m.PresaveRatingPage })));
const IdeasPage       = lazy(() => import("./pages/IdeasPage").then(m => ({ default: m.IdeasPage })));
const RecapsPage      = lazy(() => import("./pages/RecapsPage").then(m => ({ default: m.RecapsPage })));
```

Каждый роут обёрнут:
```tsx
<Route path="gallery" element={<Suspense fallback={<PageFallback />}><GalleryPage /></Suspense>} />
// … аналогично для 8 остальных
```

**Результат:** `main 1037 KB → 509 KB (−51%)`, gzip `206 → 143 KB (−31%)`. Gallery и Recaps теперь чанки `chunk-4h2d6neb.js` (154 KB) и `chunk-2y8mmf1t.js` (251 KB) — грузятся только по переходу.
