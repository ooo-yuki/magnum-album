### BUG-1 — `src/pages/games/RunnerGame.tsx:134,136,141,168,170` — TSC TS18047 `audioCtx is possibly 'null'`

После незакомиченного diff `RunnerGame.tsx` (+196 строк: `RUNNER_TIPS`, `DIFFICULTY`, `playDieSound`/`playWinSound`/`playDashSound`, `spawnWinConfetti`) `bun tsc --noEmit` падает:

```
src/pages/games/RunnerGame.tsx(134,73): error TS18047: 'audioCtx' is possibly 'null'.
src/pages/games/RunnerGame.tsx(136,71): error TS18047: ...
src/pages/games/RunnerGame.tsx(141,73): error TS18047: ...
src/pages/games/RunnerGame.tsx(168,74): error TS18047: ...
src/pages/games/RunnerGame.tsx(170,71): error TS18047: ...
```

Причины:
- `let audioCtx: AudioContext | null = null` затем `audioCtx.currentTime` без `!` и без `if (!audioCtx) return`.
- В `playDieSound` (строки 134/136/141) `safeRamp(o.frequency, () => o.frequency.linearRampToValueAtTime(48, audioCtx.currentTime + 0.38), 48)` — `audioCtx` может быть null к моменту замыкания.
- Тот же паттерн в `playWinSound` (168/170).

Риск: сборка `bun run build.ts` и CI `tsc` красные, деплой с `tsc --noEmit` в pre-commit упадёт; в рантайме при `AudioContext` suspend возможен NPE.
