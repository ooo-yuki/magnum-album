## 2) WebSocket без токена

```
curl -i -N -H "Connection: Upgrade" -H "Upgrade: websocket" http://127.0.0.1:3000/magnum/api/ws
→ HTTP/1.1 401 Unauthorized
→ {"error":"unauthorized — войди, братуха"}
```
**✅ WS защищён. Код `server.ts:2519-2527`: `extractToken(req)` → `if (!token) 401` → `getUserByToken` → `if (!user) 401` → `server.upgrade`**

```ts
// server.ts:2519
if (url.pathname === "/magnum/api/ws" || url.pathname === "/magnum/api/ws/") {
  const token = extractToken(req);
  if (!token) return Response.json({ error: "unauthorized — войди, братуха" }, { status: 401 });
  let user = null;
  try { user = await getUserByToken(token); } catch(e) {}
  if (!user) return Response.json({ error: "unauthorized — войди, братуха" }, { status: 401 });
  const ok = server.upgrade(req, { data: { id: String(user.id), username: user.username, roomId: null } });
```

## 4) Баг #1 — PII leak в frame/status

**Файл: `server.ts:881` `async function handleFrameStatus(req: Request)`**

Причина: ветка `if (user) { return user frames }` / `else { return ALL frames }` — аноним получает `SELECT ... FROM magnum_frames ... ORDER BY created_at DESC LIMIT 50` без WHERE, 200 вместо 401. Curl подтверждает:

```
curl -s http://127.0.0.1:3000/magnum/api/frame/status -w " CODE:%{http_code}"
→ {"frames":[{"id":15,"username":"freak_factory",...}, ... 15 записей],"total":15} CODE:200
```

Должно быть 401 как у `handleFrameVerify` (`server.ts:940`), `handleMiningGet` (`server.ts:1068`), `handleCoinsGet` (`server.ts:198`).

**План фикса (1 патч, 2 минуты):**

```diff
// server.ts:881-885

   try {
     const sql = getSql();

-    let user: { id: number; username: string } | null = null;

-    if (user) {
+    if (!token) return Response.json({ error: "unauthorized" }, { status: 401 });
+    const user = await getUserByToken(token);
+    if (!user) return Response.json({ error: "unauthorized" }, { status: 401 });
     // ... existing user-scoped query only
-    }
-    const rows = await sql`SELECT f.id, COALESCE(u.username, 'Братуха') ...` // DELETE anon branch
-    return Response.json({ frames, total, ... });

```

Если нужен публичный лидерборд фреймов — вынести в отдельный `GET /magnum/api/frame/leaderboard` (public, без user_id) и оставить `/frame/status` строго 401-аутентифицированным, как `/mining`, `/coins`.

**Доп. замечание (не критично, P2):** `server.ts:66 cookieForToken` без `Secure` — на HTTPS за прокси cookie уйдёт по HTTP, добавить `; Secure` когда `process.env.NODE_ENV==="production"` или `X-Forwarded-Proto`.
