### 2. `src/pages/GalleryPage.tsx:43,45,48` — `y2k-02`/`y2k-03` указывают на один файл, 3 Y2K-карточки из 4 bytes

```ts

  "y2k-01": "/magnum/images/gallery-42/42-y2k-01-800.webp", // 67K webp

### 3. `src/lib/galleryTokens.ts:49-54` + `src/pages/GalleryPage.tsx:51-55` — `getRealSrc` silent fallback на СССР маскирует soft-404

```ts

  if (style in REAL_BY_STYLE) return REAL_BY_STYLE[style]!;

  if (typeof console !== "undefined") console.warn("[gallery] unknown style", style);

}
```

До `613fb20` так же маскировался `Y2K→мемфис`. Фикс: в DEV `throw new Error`, в PROD `console.warn` + `fetch("/magnum/api/ledger/gallery-unknown", {style})` или хотя бы `import.meta.env.DEV && throw`, чтобы CI ловил.
