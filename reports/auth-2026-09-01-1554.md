### Баг #1 (средний, повторяется) — `server.ts:1966` `handleAi` открыт без auth и без rate-limit

**Файл:** `server.ts:1966` `async function handleAi(req: Request): Promise<Response>`

```ts
async function handleAi(req: Request): Promise<Response> {
  if (req.method !== "POST") return Response.json({ error: "POST only" }, { status: 405 });
  const apiKey = process.env.XIAOMI_API_KEY;
  if (!apiKey) return Response.json({ error: "XIAOMI_API_KEY not configured" }, { status: 500 });
  let body = await req.json() as { text?: string; history?: ... };
  // сразу fetch к ${MIMO_BASE}/chat/completions — без extractToken / getUserByToken / checkRateLimit
```

**Проблема:** `POST /magnum/api/ai` — единственный POST-эндпоинт без `extractToken` и без `checkRateLimit`. Любой аноним может слать `text` до 2000 + `image` dataUrl + `history` и жечь `XIAOMI_API_KEY` / MIMO-квоту (model `mimo-v2-flash` `max_tokens: 400`). В отличие от `handleEcoSubmit`/`handlePresaveClick` где анонимность осознанная (публичные счётчики), здесь — платный прокси к LLM. Нет логирования `user_id`/`ip` в `magnum_transactions`. При флуде — 502/429 от апстрима, но биллинг уже списан.

Сопоставление: `handleCoinsAdd:228`, `handleShopBuy:498`, `handleMiningClick:982` — все начинают с `const token=extractToken(req); if(!token) return 401`. `handleAi` — единственный `handle*` POST без этой строки (проверено `grep -n "^async function handle" server.ts` — 42 хендлера, все POST кроме `handleAi`, `handleIdeasVote` anon-fallback, `handleEcoSubmit` anon-fallback имеют гейт).
