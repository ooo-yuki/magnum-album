### 1) `server.ts:302` (+128,146,239,277) — пустые `catch {}` глотают ошибки auth молча (P1)

```ts
// server.ts:128  } catch {}
// server.ts:146  } catch {}
// server.ts:302  if (token) { try { authed = await getUserByToken(token); } catch {} }  ← hot-path идей
// server.ts:865/908/963 аналогично
```

Любой сбой `getUserByToken` (Neon таймаут, `DATABASE_URL` разрыв) проглатывается — запрос продолжает как анонимный без лога. В проде это маскирует деградацию БД: `journalctl -u magnum-bun` чист, но все юзеры внезапно `null`, `POST /magnum/api/ideas/:id/vote` после патча anon-блока начнёт отдавать 401 всем. Нет метрики/алерта. Фикс: `catch(e){ console.warn("[auth:ideasVote]", e instanceof Error?e.message:String(e)) }` + счётчик `authFailures`.

### 2) `src/lib/galleryTokens.ts:50` vs `src/pages/GalleryPage.tsx:787` — дублирование `getRealSrc` с рассинхроном сигнатуры (P1)

```ts
// src/lib/galleryTokens.ts:50
export function getRealSrc(style: string): string {
  return REAL_BY_STYLE_FALLBACK[style] ?? REAL_BY_STYLE_FALLBACK["СССР"]!;
}
// src/pages/GalleryPage.tsx:787
export function getRealSrc(style: Style42, src: string): string {
  if (style in REAL_BY_STYLE) return REAL_BY_STYLE[style]!;
  return src && src.startsWith("/magnum/") ? src : REAL_BY_STYLE["СССР"]!;
}
```

Два источника истины: `REAL_BY_STYLE` (GalleryPage) и `REAL_BY_STYLE_FALLBACK` (galleryTokens) дублируют 4 пути, но сигнатуры разные — lib принимает 1 arg, страница 2 args с fallback на `src`. Если править стиль в одном месте (напр. добавить `42-y2k-02.jpg`), второе не обновится → `Y2K→СССР` кросс-фоллбек, 404-guard из `P0 #1` пробивается. Сейчас `GalleryPage.tsx` не импортирует из `galleryTokens.ts`, а держит копию — нарушение DRY из `src/lib/galleryTokens.ts:1` (`extracted from GalleryPage.tsx:791`). Нужна унификация: удалить локальный `REAL_BY_STYLE` и импортировать `getRealSrc` из `galleryTokens.ts`.
