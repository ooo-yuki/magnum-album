## Оптимизация этого тика: stale bloat cleanup + postcard/covers webp + lazy + build.ts auto-cleanup

**Проблема 1 — dist bloat:** каждый `bun run build.ts` создавал новые `main-{hash}.js`/`chunk-{hash}.js`, но старые не удалялись. За 10+ тиков накопилось **24 mains + 107 chunks = 103 stale файла (14.5 MB)**, dist вырос с ~33M до 47M. `/srv/magnum` тоже 48M. Риск: диск 80%+ и деплой тащит мусор, CDN кэширует stale.

**Проблема 2 — postcard + covers без webp:** `postcard-4200.png` 242K (открытка победы в Blackjack/Roulette) грузилась как PNG `loading="eager"` — блокировала модалку. `repit.jpg` 234K, `vpn.jpg` 328K в covers без `-800.webp`, `tusa-meduza.jpg`/`vpn.jpg` 68K без webp.

**Решение (3 файла + 1 патч + 5 webp):**

1. **Stale cleanup — текущий + автоматический:**
   - Ручная чистка: по `dist/.build-manifest.json` valid set удалено **103 stale** (14.5 MB), dist 47M→34M, `/srv/magnum` 48M→33M
   - `build.ts:1744` патч — после `Bun.write index.html` stale cleanup по `validSet` (outputs + index/sitemap/robots), логирует `🧹 stale cleanup: removed N files (XB)` — будущие билды авто-чистые

2. **Postcard 4200 → webp + picture + lazy (2 игры):**
   - `public/images/postcard-4200-800.webp` — **154K webp q80** vs 242K PNG (−35%)
   - `BlackjackGame.tsx:760` + `RouletteGame.tsx:484`: `<img eager PNG>` → `<picture><source webp /><img lazy PNG fallback /></picture>`
   - `loading="eager"` → `loading="lazy"` (модалка не LCP, грузится по клику)

3. **Covers + tusa/vpn → 800px webp (4 доп):**
   - `repit-800.webp` 82K vs 234K (−65%), `vpn-800.webp` 21K vs 328K (−93%)
   - `tusa-meduza-800.webp` 27K vs 69K (−60%), `vpn-800.webp` 15K vs 67K (−77%)
   - Synced `public/images` → `dist/images` → `/srv/magnum/images` (build `cp -r` + manual cp)

**Эффект:**
- dist: **−14.5 MB (−29%)** мгновенно, будущие билды без накопления (auto-cleanup)
- postcard modal: **−88K (−35%)** на каждом победе Blackjack/Roulette, lazy не блокирует main thread
