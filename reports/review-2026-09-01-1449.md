## Замечания (3 конкретных)

1. **`src/lib/galleryTokens.ts:42` + `src/pages/GalleryPage.tsx:39-40` — Y2K алиасится на memphis (дубликат 25% галереи):**
   ```ts
   // src/lib/galleryTokens.ts:41-44
   "СССР": "/magnum/images/gallery-42/42-agit-01-800.webp",    // ok
   "Y2K": "/magnum/images/gallery-42/42-memphis-01-800.webp",   // <- БАГ: должен быть 42-y2k-01-800.webp
   // src/pages/GalleryPage.tsx:39-43 REAL_FALLBACK
   "y2k-01": "/magnum/images/gallery-42/42-memphis-01-800.webp", // <- БАГ: y2k -> memphis
   "y2k-02": "/magnum/images/gallery-42/42-memphis-01.jpg",      // <- БАГ: y2k -> memphis.jpg
   "y2k-03": "/magnum/images/gallery-42/42-cyber-01.jpg",        // <- БАГ: y2k-03 -> cyber.jpg
   ```
   Факт: `md5sum 42-memphis-01.jpg == 42-y2k-01.jpg (788871292a778b8b4c2d20645924c911)` — один PNG продублирован под двумя именами, `file` -> оба `PNG image data 1536x1024` (расширение `.jpg` врет, Caddy отдает `image/jpeg` для PNG). Y2K и Memphis показывают одну картинку, уникальных визуалов — 3 вместо 4. При этом `GalleryPage.tsx:32 REAL_BY_STYLE["Y2K"]` -> верно `42-y2k-01-800.webp`, а `REAL_FALLBACK["y2k-01"]` -> неверно memphis — рассинхрон. Фикс: `galleryTokens.ts:42 -> 42-y2k-01-800.webp`, `GalleryPage.tsx:39-40 -> 42-y2k-01.*`, либо убрать FALLBACK и везде `getRealSrc(style)`, пересохранить PNG как JPEG (`magick ... -quality 85`) или переименовать в `.png`.
