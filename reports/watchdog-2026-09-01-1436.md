### BUG-1 — `server.ts:316` — anon-голоса без дедупа, спам накрутки

```ts

// 299 checkRateLimit(`ideas:vote:${ip}:${id}`, 12, 60_000) // только rate-limit

// 316 // anon: allow vote but rate limited by IP, no dedup persistence
// 317 const rows = await sql`UPDATE magnum_ideas SET votes = ... +1 WHERE id=${id} RETURNING *`;
```

Комментарий обещает `rate limited by IP`, но защита — лишь `12/min` на IP+id. Без таблицы анонов один IP может накрутить `65` -> `142->inf` за минуты (ротация IP/прокси = бесконечность). Аутентифицированные защищены `magnum_idea_votes UNIQUE(user_id,idea_id)`, анонимы — нет. Риск: топ идей полностью манипулируем; `votes` перестаёт быть метрикой сообщества. Подтверждение: `curl` без токена -> `{"idea":..., "anon":true}` каждый раз +1, без `409`.
