## Найденный баг

**Файл: `server.ts:2234` (`handleAi`) + маршрут `server.ts:2461`**

```ts
// server.ts:2234
async function handleAi(req: Request): Promise<Response> {
  if (req.method !== "POST") return Response.json({error:"POST only"},{status:405});
  const apiKey = process.env.XIAOMI_API_KEY; // ← нет проверки токена!
  // ... сразу проксирует в Mimo без extractToken/getUserByToken
}
// server.ts:2461
if (url.pathname === "/magnum/api/ai") return handleAi(req); // ← нет auth-gate
```

**Факт из curl:** `curl -s -X POST -H "Content-Type: application/json" -d '{"prompt":"hi"}' http://127.0.0.1:3000/magnum/api/ai` без cookie → `500` (нет ключа) вместо `401`. При установленном `XIAOMI_API_KEY` — аноним получит `200` и сожжёт ключ/квоту. Все остальные `POST /magnum/api/*` (shop, mining, coins, games, chat) корректно дают `401`.

**Вторичный нюанс (не критично, но фиксить вместе):** `server.ts:57-62` `extractToken` читает `?token=` из URL — токен утекает в логи Nginx/историю браузера/Referer. WS позволяет `?token=` для `new WebSocket("/magnum/api/ws?token=...")` — это удобно, но для `/magnum/api/ai` и остальных API `?token=` не нужен.

## План фикса (по шагам, без отмазок)

1. **Закрыть AI:** в `handleAi` первой строкой:

   if (!token) return Response.json({error:"unauthorized"},{status:401});

   if (!user) return Response.json({error:"unauthorized"},{status:401});
   if (!checkRateLimit(`ai:${user.id}:${getClientIp(req)}`, 10, 60_000))
     return Response.json({error:"rate limited"},{status:429});

2. **Маршрут:** оставить `server.ts:2461` как есть (проверка внутри `handleAi`) или вынести gate наружу — главное чтобы POST без токена дал `401`, а не `500/200`.
3. **Опционально убрать `?token=` для HTTP API:** в `extractToken` оставить `?token=` только для WS (`url.pathname === "/magnum/api/ws"`), для остальных — только `Authorization: Bearer` и `cookie: magnum_token`.
