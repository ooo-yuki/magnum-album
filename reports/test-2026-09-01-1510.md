## 5. 3 идеи для новых тестов

1. **gallery onError 404 → gradient интеграция** — рендер `GalleryPage` в jsdom, мокаем `img.onerror`, проверяем что после ошибки `src` заменяется на `gradient` div, а не оставляет битую картинку 404. Сейчас тест только проверяет наличие `onError` строки, но не реальный фолбэк-поведение.
2. **GamesHub GSAP ScrollTrigger batch 200 для 16 карточек** — рендер `GamesHub` с `gsap` моком, скролл-триггер должен `batch` анимировать карточки `stagger 0.12` через `gsap.set()+to()` (не `from()`), проверка `prefers-reduced-motion` отключает анимацию. Поймает регрессию IIFE bundle где `from()` не анимирует.
3. **API health 200 contract + coins/add 200 с auth** — `fetch` моком к `server.ts` handleHealth: `GET /magnum/api/health` → 200 `{ok:true, counts:{magnum_users,magnum_coins}}`; `POST /magnum/api/coins/add` без `Bearer` → 401, с `Bearer` + валидным `amount` → 200 `{balance}`, с `amount=0` → 400. Сейчас тесты только `toContain` строк, не HTTP контракт.
