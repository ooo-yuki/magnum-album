## Найденные баги (файл:строка)

### 1) `server.ts:128` (+302,865,908,963) — пустые `catch {}` глотают ошибки молча (P1)

```ts
// server.ts:128 — пример, таких 8 мест
} catch {}
// ещё:
// server.ts:302  if (token) { try { authed = await getUserByToken(token); } catch {} }
// server.ts:865  if (token) { try { user = await getUserByToken(token); } catch {} }
// server.ts:908,963 аналогично
```

Любой сбой `getUserByToken` (Neon таймаут, `DATABASE_URL` разрыв) проглатывается — запрос продолжает как анонимный без лога. В проде это маскирует деградацию БД: `journalctl -u magnum-bun` чист, но все юзеры внезапно anon, `POST /magnum/api/ideas/:id/vote` после патча anon-блока начнёт отдавать 401 всем. Нет метрики/алерта. Фикс: заменить на `catch(e){ console.warn("[auth] getUserByToken failed", e) }` или централизованный `safeAuth()`.

### 2) `src/components/AiBot.tsx:80` — `as any` + небезопасный парсинг inventory (P1)

```ts
// AiBot.tsx:80
if(ir.ok){ const d=await ir.json() as {inventory?:Array<{skin_id:string;skinId:string}>;items?:Array<{skin_id:string}>}; const arr=(d as any).inventory|| (d as any).items|| (Array.isArray(d)?d:[]); owned = arr.map((x:any)=> String(x.skin_id||x.skinId||x)); }
```

Тройной `as any` обходит `strict` из `tsconfig.json: strict:true`. Если `/magnum/api/shop/inventory` вернёт `{error:"unauthorized"}` (401 без токена), `arr` станет `[]` только если `Array.isArray(d)` false — но `(d as any).inventory` undefined, `(d as any).items` undefined, `Array.isArray(d)` false → `arr=[]` случайно OK, но `x.skin_id` на `{error}` не проверяется. Хуже: при `200 {inventory: null}` → `arr=null` → `.map` краш `TypeError: arr.map is not a function` — весь `AiBot` падает, чат MAGNUM ломается. Рядом `ShopPage.tsx:384` `batch:any` и `568 as any` — тот же класс. Нужен `zod`/type-guard.
