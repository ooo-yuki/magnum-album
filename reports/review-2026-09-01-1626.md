```ts

  "СССР": "/magnum/images/gallery-42/42-agit-01-800.webp",

  ...
}
// galleryTokens.ts:41-44 — идентичная копия
export const REAL_BY_STYLE_FALLBACK: Record<string,string> = {
  "СССР": "/magnum/images/gallery-42/42-agit-01-800.webp",
  ...
}
```

`1a835a2` вынес `TOKENS` в `galleryTokens.ts:1-35` (хорошо), но оставил `REAL_BY_STYLE` продублированным вместо импорта. Фикс: удалить дубль в `GalleryPage.tsx`, `import { REAL_BY_STYLE_FALLBACK as REAL_BY_STYLE } from "@/lib/galleryTokens"` + удалить `REAL_FALLBACK` дубль (38-43) — оставить один `getRealSrc`.

### 2. `src/lib/galleryTokens.ts:45-48` — `getRealSrc` молчаливый fallback на СССР скрывает баг

```ts
// galleryTokens.ts:45
export function getRealSrc(style: string): string { 
  return REAL_BY_STYLE_FALLBACK[style] ?? REAL_BY_STYLE_FALLBACK["СССР"]!; 
}
```

Неизвестный стиль (опечатка `"ссср"` / `"Y2k"`) тихо отдаёт агит-плакат вместо ошибки. В `ARCHIVE_42` 210 записей фильтр по несуществующему стилю покажет чужой арт без логов. Фикс: `if (!(style in REAL_BY_STYLE_FALLBACK)) console.warn("[gallery] unknown style", style)` + метрика, или `throw` в dev. Сейчас маскирует soft-404 как было с `y2k→мемфис` до `613fb20`.
